Chaoxing Ally
一个用于超星学习通页面的 Tampermonkey 辅助脚本。它可以提取页面题目、请求候选答案，并在用户明确确认后填入答案。

功能
提取题干和选项
调用 DeepSeek API 获取候选答案
用户确认后填入答案
支持停止请求和离线自检
不自动提交试卷
安装
在浏览器中安装 Tampermonkey。
打开 chaoxing-ally.user.js 的原始文件页面。
点击 Tampermonkey 的安装按钮。
通过 Tampermonkey 菜单设置自己的 DeepSeek API Key。
隐私说明
题干和选项会发送到 DeepSeek API 以生成候选答案。
API Key 由用户自行设置，项目中不包含任何预设密钥。
使用前请自行评估课程内容、个人信息和学校规定是否允许发送给第三方服务。
使用边界
候选答案可能出错，请务必自行核对。本项目不自动交卷，不应被用于绕过课程要求、考试规则或学校规定。
